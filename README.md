# My-Site
A simple personal portfolio website built with HTML, CSS, Bootstrap, and JavaScript.

## What this project contains
- Home page with an introduction and interests
- Experience, education, skills, projects, and contact pages
- Responsive navigation and a clean, modern layout

## How to update your information
- Edit the text directly in the HTML files for your bio, experience, education, and contact details
- Replace the placeholder project cards in the Projects page with your real work
- Update images, links, and social profiles as needed

## Preview locally
Open the project folder in a browser, or run a simple local server from the workspace folder.
